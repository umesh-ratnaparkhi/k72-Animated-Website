# 🌟 k72 Animated Website

A visually stunning, high-performance animated website featuring advanced micro-interactions, smooth kinetic scrolling, and immersive UI layouts. 

## 🚀 Live Demo
🔬 **Deployment Link:** [View Live Site](https://github.com) *(Replace with your actual deployment link if using Vercel/Netlify)*

---

## ✨ Features
*   **Kinetic Scrolling:** Integrated smooth layout inertia for a premium, heavy-weight scrolling experience.
*   **Dynamic Timelines:** Complex, sequential element triggers that reveal content seamlessly as the user scrolls.
*   **Responsive Fluid Layouts:** Tailored media queries ensuring typography and animations translate perfectly across mobile, tablet, and desktop viewports.
*   **Optimized Performance:** Clean asset rendering and optimized painting cycles to prevent layout shifts.

---

## 🛠️ Tech Stack

*   **Frontend:** HTML5, CSS3 / SCSS, JavaScript (ES6+)
*   **Animation Libraries:** GSAP (GreenSock Animation Platform), Locomotive Scroll
*   **Asset Management:** High-resolution optimized media rendering

## ⚙️ Installation & Local Setup

Follow these steps to run the project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone git@github.com:umesh-ratnaparkhi/k72-Animated-Website.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd k72-Animated-Website
   ```

3. **Launch a Local Server:**
   * If you are using VS Code, right-click `index.html` and select **Open with Live Server**.
   * Alternatively, use Python to host it instantly:
     ```bash
     python -m http.server 8000
     ```
     Then open `http://localhost:8000` in your browser.

## 💡 Animation Architecture Details
*   **Standard Compatibility:** Implements modern `background-clip` paradigms for high-fidelity text-mask treatments across all modern rendering engines.
*   **Scroll Interception:** Custom configuration of scroller proxies ensuring layout triggers align with hardware-accelerated transforms.
